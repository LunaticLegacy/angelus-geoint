# 原生工作空间与文件选择

## 目标

1. 在 GEOINT 会话管理卡片中显示当前会话的最终工作空间绝对路径。
2. 在桌面版中以操作系统原生文件选择器导入 GIS 文件，并能用系统默认文件管理器打开工作空间。

## 非目标

- 不向 WebView 暴露原始文件绝对路径或通用宿主文件系统 API。
- 不改变浏览器部署：没有 Tauri bridge 时继续使用标准 `FileList` 上传。
- 不允许前端任意指定要由桌面进程打开的路径。

## 风险与约束

- 原生选择得到的路径只可停留在 Rust shell；它只可流式上传到当前已选择会话。
- 打开目录只能使用当前 session 的 `Workspace.project_path`，不得接收前端路径参数。
- Tauri command 是唯一额外能力，需被 desktop capability 明确允许。
