# 模块边界

| 包 | 职责 | 不负责 |
| --- | --- | --- |
| `analysis` | 干旱模型、几何、CRS、本地分析资产与结果 | 地图文档、上传协议 |
| `assets` | 资产目录、受限远程下载 | Session 地图状态 |
| `mapping` | 底图、地图文档、图层记录、栅格显示与瓦片代理 | 导入原始文件 |
| `ingestion` | 声明、存储、检查、格式转换、导入发布 | 资产目录的持久化实现 |
| `processing` | 基于已登记资产的派生计算 | 上传和浏览器显示 |
| `agent` | 受限的会话 GEOINT 工具 | 直接读写主机路径 |
| `runtime` | 组合以上服务并注入 Session 守卫 | HTTP 参数解析 |

`angelus.geoint` 顶层仅是 facade：应用层从这里导入公共服务、错误和工厂；包内模块使用相邻语义包的显式导入，避免回环依赖。
